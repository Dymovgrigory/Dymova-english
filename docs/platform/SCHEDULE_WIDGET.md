# Виджет расписания и записи (fxb-schedule.js)

## Подключение на странице сайта

```html
<div id="fxb-schedule"></div>
<script src="https://bot.dymova-english.ru/widget/fxb-schedule.js" defer></script>
```

CORS: origin сайта должен быть в SITE_CORS_ORIGINS (уже есть
dymova-english.ru / new.dymova-english.ru).

## Что делает

1. Загружает /api/platform/{filials,groups,schedule} (единый backend-источник —
   на сайте, в боте и мини-аппе данные одинаковые).
2. Показывает карточки активных групп: название, филиал, ближайшее занятие,
   свободные места (🟢 / 🟠 «мало мест» по LOW_AVAILABILITY_THRESHOLD).
3. «Записаться на пробное» → модальная форма (родитель, телефон, ребёнок,
   возраст) с inline-валидацией → POST /api/platform/booking с
   idempotency_key.
4. Anti-race на бэкенде: если место заняли — виджет показывает «Место только
   что заняли» + альтернативные группы одним кликом.
5. Под карточками — свежесть данных («обновлено N мин назад»), из ответа API.
6. Состояния: skeleton при загрузке, понятная ошибка с «Повторить», пустой
   стейт с подсказкой, мобильная вёрстка (bottom-sheet модалка, 48px тач-цели),
   prefers-reduced-motion, Escape/клик-фон для закрытия.
