## Правила публикации (одинаковые для всех)

- В описании **первой строкой** — ссылка на релевантную страницу сайта (YouTube/RuTube делают её кликабельной).
- Геометка: Долгопрудный. Категория: «Образование».
- В конце описания — общий блок: «Языковая школа «Фоксинбург», Долгопрудный: английский, немецкий и китайский для детей от 2 до 18 лет и взрослых. Сайт: https://dymova-english.ru»
- Теги-основа для всех: `английский для детей`, `языковая школа`, `Долгопрудный`, `Фоксинбург`, `английский для детей Долгопрудный`.
- Названия каналов: «Языковая школа Фоксинбург | Долгопрудный». VK-группа уже есть: vk.com/foxyfoxclub.
- Плейлисты: «Жизнь школы», «Праздники», «Занятия», «Дети говорят», «Академии», «Выпускной».
