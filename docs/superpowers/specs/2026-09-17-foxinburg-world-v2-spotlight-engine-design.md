# Foxinburg World v2 — движок обучения по Spotlight 1–4

**Дата:** 2026-09-17
**Ветка:** `world-v2` (от снимка `backup/world-agent-0916`)
**Статус:** дизайн согласован владельцем в чате 2026-09-17

---

## 1. Зачем

Цель платформы сейчас — привлечь школьников, у которых проблемы с английским в
школе. Школьник выбирает свой класс и модуль, который проходят в классе, и
тренирует **ровно ту лексику и грамматику из учебника Spotlight**, короткими
уроками как в Duolingo, с приёмами Puzzle English (сборка фразы, короткие
правила, личный словарь). Замок Фоксинбурга — развлекательный слой наград, он
никогда не мешает учиться.

Прошлая версия (`foxinburg-world-v1`) провалилась: урок — стена текста из 32
шагов, путь — простыня на 12 000 px, замок и счётчики перебивают обучение,
визуально разнобой. Бэкенд (игрок, токен, TTS, SRS, деплой) пригоден и
переиспользуется.

## 2. Объём этапа 1

**Входит:**
- Движок урока (сборка, проверка, очередь ошибок, награда).
- Путь обучения: учебник → модуль → узлы.
- Онбординг «Мой класс»: имя → класс → текущий модуль → дневная цель.
- Контент **Spotlight 1, 2, 3, 4 — все модули** (лексика и грамматика 1:1 с
  учебником, предложения свои).
- Тренировка (повтор по SRS) и Мой словарь — в минимальном виде (раздел 7).
- Дизайн-система и новый фронтенд урока/пути.
- Арт Meshy: Foxy с прозрачным фоном, иллюстрации модулей, картинки слов.
- Вкладка «Замок» открывает существующий `CastleHub` как есть.

**Не входит (следующие этапы):** Spotlight 5–11 и режим Teens, сердца, лиги,
сундуки с лутом (на этапе 1 сундук даёт фиксированные монеты), переделка
замка, аккаунты родителей, ИИ-репетитор.

## 3. Правовая рамка контента

- 1:1 с учебником: состав и порядок модулей, названия тем, списки слов,
  грамматические темы, типы навыков.
- Своё: все предложения, мини-тексты, аудио (edge-tts), картинки (Meshy).
- Не используем: тексты, диалоги, упражнения, аудио, иллюстрации и имена
  персонажей учебника. Главный персонаж — Foxy.
- В интерфейсе: «Тренажёр к учебнику Spotlight», без логотипов издательства.

## 4. Структура обучения

```
Учебник (Spotlight 1…4, бейдж CEFR)
  └─ Модуль (как в учебнике: Starter, Module 1…N)
       └─ Узлы пути (строго по порядку)
            words ×2–3 → [phonics ×1–2 — SP1–2] → phrases/grammar ×1–2 → chest
            → review → module_test
```

CEFR: SP1 — Pre-A1, SP2 — Pre-A1, SP3 — A1, SP4 — A1.

### 4.1 Линия чтения (SP1–2)

Отдельная сквозная программа phonics, привязанная к модулям: узлы `phonics`
в каждом модуле SP1–2 вводят 2–4 буквы/звука и читают слова из лексики этого и
прошлых модулей, собранные только из уже изученных звуков.

| Ступень | Что умеет ребёнок | Задания |
|---|---|---|
| 1. Буква–звук | узнаёт букву по звуку и звук по букве | `letter_sound`, `sound_letter` |
| 2. Слияние | сливает 2–3 звука в слог/слово (c-a-t → cat) | `blend_sounds` |
| 3. Чтение слов | читает слово без звука и понимает его | `read_word_pick_image` |
| 4. Буквосочетания | sh, ch, th, ee, oo, ck, … (SP2) | `letter_sound`, `blend_sounds` |
| 5. Чтение фраз | читает фразу из 2–4 слов без звука | `read_phrase_pick_image` |

Порядок звуков хранится в `content/spotlight/phonics_sequence.json` (SP1:
одиночные буквы в порядке satpin-подобной последовательности; SP2: алфавит
учебника + буквосочетания). Инвариант: слово попадает в задание на чтение,
только если все его графемы уже введены (кроме «trick words» — список на
модуль, вводятся отдельной карточкой `teach_word`).

Возрастные «полосы» определяют набор типов заданий:
- `starter` (SP1–2): **учим читать.** Задания идут от звука и картинки к
  самостоятельному чтению: буква → звук → слияние звуков → чтение слова →
  чтение короткой фразы. Инструкции с кнопкой озвучки.
- `junior` (SP3–4): чтение, сборка фраз, грамматический выбор, набор слова.

**Мой класс:** выбранный модуль становится текущим узлом; все узлы предыдущих
модулей этой книги открыты (не пройдены) — можно догнать класс. Книги ниже
выбранной тоже открыты. Смена класса/модуля — в Профиле.

## 5. Контент: модель данных

Файл на модуль: `world-backend/content/spotlight/sp{N}/{module_id}.json`,
валидируется pydantic-схемой при загрузке и в тесте.

```jsonc
{
  "id": "sp2.m1",
  "book": "sp2",
  "order": 2,
  "title_en": "My Home!",          // название модуля как в учебнике
  "title_ru": "Мой дом",
  "band": "starter",
  "words": [
    { "id": "sp2.m1.bed", "en": "bed", "ru": "кровать",
      "accept_en": [], "accept_ru": ["постель"],
      "kind": "noun", "image": "words/bed.webp" }
  ],
  "phrases": [
    { "id": "sp2.m1.p3", "en": "The bed is in the bedroom.",
      "ru": "Кровать в спальне.",
      "accept_en": ["The bed's in the bedroom."],
      "word_ids": ["sp2.m1.bed", "sp2.m1.bedroom"],
      "grammar_id": "sp2.m1.g-where" }
  ],
  "grammar": [
    { "id": "sp2.m1.g-where", "title_ru": "Where is…? — Где…?",
      "rule_ru": "1–3 коротких предложения.",
      "examples": [{ "en": "Where is the cat?", "ru": "Где кошка?" }],
      "items": [
        { "id": "sp2.m1.g-where.1", "prompt_en": "___ is the ball?",
          "options": ["Where", "What"], "answer": 0, "ru": "Где мяч?" }
      ] }
  ],
  "phonics": [ { "id": "sp2.m1.ph-a", "letter": "a", "sound_word": "apple" } ],
  "nodes": [
    { "id": "sp2.m1.n1", "kind": "words", "word_ids": ["…5–6 шт."] },
    { "id": "sp2.m1.n4", "kind": "grammar", "grammar_id": "sp2.m1.g-where" },
    { "id": "sp2.m1.n6", "kind": "chest" },
    { "id": "sp2.m1.n7", "kind": "review" },
    { "id": "sp2.m1.n8", "kind": "module_test" }
  ],
  "sources": ["URL оглавления/КТП/Word List, по которому сверено"]
}
```

Инварианты (проверяются тестом `test_content.py`):
- уникальные id по всему курсу;
- каждый `word_ids`/`grammar_id` ссылается на существующий атом;
- каждое слово модуля входит хотя бы в один узел `words`;
- у каждой фразы все слова, кроме служебных (`a, the, is, …` — список в коде),
  есть в этом или предыдущих модулях курса;
- `sources` не пуст.

**Конвейер наполнения:** оглавление + Word List модуля из ≥2 открытых
источников → черновой JSON (Claude) → валидатор → ручная выборочная сверка
(владелец/преподаватель) по чек-листу в `content/spotlight/REVIEW.md`.

## 6. Движок урока (backend)

Новый пакет `world-backend/app/learning/`, API под префиксом `/api/v2`.
Старые `/api/world/learn/*` не трогаем до удаления старого фронта (этап 1,
последняя задача), замковые эндпоинты остаются.

| Модуль | Ответственность |
|---|---|
| `content.py` | загрузка и валидация JSON, индекс атомов, порядок узлов |
| `challenges.py` | типы заданий: сборка payload из атома + эталон ответа |
| `builder.py` | состав сессии по узлу, полосе и SRS (детерминирован по `seed`) |
| `checker.py` | нормализация и проверка ответа |
| `progress.py` | прохождение узлов, XP, серия дней, дневная цель, монеты |
| `mastery.py` | сила атома (Лейтнер 0–5, интервалы как в `srs.py`), выборка слабых |
| `api.py` | HTTP-слой |

### 6.1 Типы заданий этапа 1

| type | Что делает ученик | Полосы |
|---|---|---|
| `teach_word` | новое слово: картинка + звук + перевод, «Дальше» (не оценивается) | обе |
| `teach_rule` | карточка правила: 1–3 строки + 2 примера со звуком (не оценивается) | обе |
| `listen_pick_image` | слушает слово → выбирает картинку из 3–4 | обе |
| `image_pick_word` | видит картинку → выбирает английское слово | обе |
| `translate_pick` | слово/короткая фраза → выбрать перевод (EN→RU или RU→EN) | обе |
| `match_pairs` | 4–5 пар: звук↔картинка (`starter`) или EN↔RU | обе |
| `letter_sound` | слышит звук/слово → выбирает букву или буквосочетание | starter |
| `sound_letter` | видит букву → выбирает звук из 3 аудио-кнопок | starter |
| `blend_sounds` | буквы подсвечиваются по звуку, затем слитно → выбрать картинку/слово | starter |
| `read_word_pick_image` | читает слово **без звука** → выбирает картинку | starter |
| `read_phrase_pick_image` | читает фразу 2–4 слова без звука → выбирает картинку | starter (SP2) |
| `spell_tiles` | собрать слово из букв-плиток по картинке и звуку | обе |
| `build_phrase` | «Пазл»: собрать английскую фразу из плиток по русскому | junior (+ SP2 фразы ≤4 слов) |
| `listen_build` | услышать фразу → собрать из плиток | junior |
| `grammar_pick` | выбрать форму в пропуске | junior (+ SP2 простые) |
| `type_word` | напечатать слово по картинке/звуку | junior |
| `speak` | произнести фразу; «Не могу говорить» отключает на 15 мин | обе |

Проверка `speak`: Web Speech API на клиенте, сравнение распознанного текста
checker'ом; если API недоступен — задание не выдаётся.

### 6.2 Сборка сессии

- Узел `words`: для каждого из 5–6 новых слов — `teach_word`, затем 2–3
  оцениваемых задания на это слово разными типами; в конце `match_pairs`.
  Итого 12–16 оцениваемых заданий.
- `grammar`: `teach_rule` → 8–12 заданий (`grammar_pick`, `build_phrase`,
  `translate_pick` на фразах с этим `grammar_id`).
- `phonics`: `teach_*` новых графем → `letter_sound`/`sound_letter` →
  `blend_sounds` → `read_word_pick_image` → `spell_tiles`; в SP2 в конце
  `read_phrase_pick_image`. 12–16 заданий. Слова — по инварианту 4.1.
- В узлах `words` полосы `starter` после изученных графем часть заданий
  заменяется на `read_word_pick_image` (закрепление чтения на лексике модуля).
- `review`: 15 заданий по атомам модуля, приоритет слабым (mastery).
- `module_test`: 15 заданий без `teach_*`, ошибки не возвращаются; результат —
  звёзды 1–3 (≥60 / ≥80 / ≥95 %); проходной порог 60 %.
- Во все сессии, кроме `module_test`, подмешиваются до 3 заданий на атомы
  прошлых модулей с наступившим сроком повторения.
- Одно и то же задание не идёт дважды подряд; один тип не больше 3 раз подряд.

### 6.3 Цикл ответа

```
POST /api/v2/sessions            {node_id}         → {session_id, challenges[] без эталонов}
POST /api/v2/sessions/{id}/answer {index, answer}  → {correct, solution, typo?, requeued}
POST /api/v2/sessions/{id}/finish                  → {xp, accuracy, duration_sec, streak, daily_goal, coins, node_completed, unlocked_node_id}
```

- Эталоны хранятся только на сервере (как в v1).
- Неверный ответ → задание ставится в конец очереди (кроме `module_test`).
  Сессия завершается, когда очередь пуста.
- `finish` идемпотентен (`idempotency_key = session_id`), повторный вызов
  возвращает тот же результат.
- Каждый ответ пишется в `attempts`.

### 6.4 Checker

Нормализация: регистр, пробелы, крайняя пунктуация, `’`→`'`, сокращения
(`it's`=`it is`, `I'm`=`I am`, `isn't`=`is not`, `don't`=`do not`, …).
Принимаются `en` и `accept_*`. Опечатка: расстояние Левенштейна 1 для слов от
5 букв → `correct: true, typo: true` (показываем «Проверь написание: …»).
Для плиточных заданий сравнивается последовательность токенов.

### 6.5 Прогресс и награды

- XP: 10 за узел + 5 за сессию без ошибок; `module_test` — 10 × звёзды.
- Дневная цель: 10 / 20 / 30 XP (выбор в онбординге).
- Серия дней: день засчитан при ≥1 завершённой сессии (по Москве, UTC+3).
- Монеты: 5 за сессию, 30 за `chest`, 50 за первое прохождение
  `module_test`. Тратятся в замке (существующий магазин).
- Операции с XP/монетами — через существующие `xp_transactions` /
  `coin_transactions` с `idempotency_key`.

### 6.6 Новые таблицы

```sql
learner_profile(player_id PK, book_id, module_id, daily_goal_xp, band, created_at, updated_at)
node_progress(player_id, node_id, status, stars, best_accuracy, completed_at, PK(player_id,node_id))
learn_sessions(id PK, player_id, node_id, payload, queue, answers, status, started_at, finished_at, result)
attempts(id PK, player_id, session_id, node_id, challenge_type, atom_id, answer,
         correct, typo, response_ms, attempt_no, created_at)
atom_mastery(player_id, atom_id, strength, correct_count, wrong_count, due_at, updated_at, PK(player_id,atom_id))
daily_activity(player_id, day, xp, sessions, PK(player_id,day))
```

Схема добавляется в `db.py` тем же механизмом, что и v1 (SQLite локально,
Postgres-адаптер на сервере).

## 7. Фронтенд

Проект `world/` (Next 16, React 19, Tailwind 4). Добавляется `motion`
(Framer Motion). Старые экраны `learn/*`,
`page.tsx`-cinematic удаляются в конце этапа; `CastleHub` и его ассеты
остаются под `/castle`.

### 7.1 Маршруты

| Маршрут | Экран |
|---|---|
| `/` | нет игрока → онбординг; есть → редирект на `/learn` |
| `/onboarding` | имя → класс (карточки SP1–4) → модуль → цель → старт первого узла |
| `/learn` | путь текущей книги |
| `/lesson/[sessionId]` | урок (полноэкранный, без меню) |
| `/practice` | вход в тренировку + счётчик слабых слов |
| `/words` | мой словарь: слова по модулям, сила, «Послушать» |
| `/castle` | существующий замок |
| `/profile` | имя, класс/модуль, цель, серия, XP |

Нижнее меню (мобайл) / левая колонка (≥1024 px): Путь · Тренировка · Словарь ·
Замок · Профиль. Верхняя полоса на пути: серия 🔥, XP сегодня/цель, монеты.

### 7.2 Путь

- Заголовок модуля — липкая плашка: «Spotlight 2 · Модуль 1 · My Home!» +
  иллюстрация модуля + кнопка «Правила модуля».
- Узлы — круглые объёмные кнопки, змейкой (смещение по синусоиде), 72 px.
  Состояния: пройден (заливка + галочка), текущий (пульс + Foxy рядом +
  поповер «Начать»), открыт, закрыт (серый). `chest` и `module_test` — свои
  иконки.
- Рендерятся только модули текущей книги; переключатель книг вверху.
- При входе — автоскролл к текущему узлу.

### 7.3 Урок

- Верх: крестик (подтверждение выхода), прогресс-бар (оценённые/всего).
- Центр: инструкция (крупно, RU, кнопка озвучки для `starter`), задание.
- Низ: «Проверить» (неактивна без ответа) → плашка результата снизу:
  зелёная «Верно!» / красная «Правильный ответ: …», кнопка «Дальше».
- Звуки верно/неверно (есть `sfx.ts`), вибрация на мобайле.
- Экран финиша: Foxy (поза по точности), XP, точность, время, анимация серии
  и дневной цели, «Продолжить».
- Клавиатура на десктопе: 1–4 для вариантов, Enter — проверить/дальше.

### 7.4 Дизайн-система

- Фон учёбы светлый `#FBF8F3`, текст `#241a30`; бренд: фиолетовый `#3a2953`,
  жёлтый `#f5ed75` (главная кнопка), бирюзовый `#7fd8c9` (успех), коралловый
  `#ff7a6b` (ошибка).
- Шрифты: Nunito (текст, 17–20 px в уроке), Montserrat ExtraBold (заголовки).
- Кнопки «нажимаемые»: нижняя грань 4 px темнее, при нажатии сдвиг на 4 px.
- Радиусы 16/24, мягкие тени, никаких белых карточек на тёмном фоне в уроке.
- Анимации только: результат ответа, завершение урока, пульс текущего узла,
  раскрытие сундука. `prefers-reduced-motion` отключает всё, кроме смены
  состояния.
- Компоненты в `world/src/design/`: `Button`, `ChoiceCard`, `Tile`,
  `ProgressBar`, `FeedbackSheet`, `PathNode`, `StatPill`, `FoxyPose`.
- Доступность: контраст AA, зоны нажатия ≥48 px, фокус-кольца, `aria-live`
  для результата ответа.

## 8. Арт (Meshy)

## 9. Ошибки и устойчивость

- Сеть упала на `answer` → повтор 2 раза, затем плашка «Нет связи» с кнопкой
  «Повторить»; прогресс сессии на сервере не теряется.
- Сессия протухла (>2 ч) → `410`, клиент предлагает начать узел заново.
- Нет картинки у слова → builder не выдаёт типы с картинкой.
- TTS недоступен → кнопка звука скрыта, задания `listen_*` не выдаются.
- Невалидный контент → backend не стартует (fail fast), CI падает.
