# Замок, этап 4: связность зданий — спека и план

**Дата:** 2026-09-18
**Статус:** согласовано владельцем («продолжай разрабатывать»)
**Ветка:** `world-v2`
**Спека-источник:** `docs/superpowers/specs/2026-09-17-castle-meta-design.md` (раздел «Связность зданий»)

## Цель

Здания перестают быть витринами и начинают кормить друг друга: слова дают сундуки,
двор — ежедневное испытание, Беседка раздаёт задания дня и недели и ведёт в нужное
здание, Башня Славы показывает трофеи прошлых недель.

## Найденные при разведке пробелы (чиним в этом этапе)

1. **Ветка Словесника считает по мёртвой таблице.** `app/castle/counters.py` читает
   `word_stats` (v1), а тренажёр v2 пишет только `atom_mastery`. Для игроков v2 ветка
   не растёт никогда. То же у Беседки: `learn.daily_quests` читает `lesson_progress`
   (v1) — «Пройди 1 урок» и «Урок без ошибок» для игроков v2 мертвы.
2. История лиги (`league_weeks`, этап 1) пишется, но наружу не отдаётся.

## Состав работ

### T1. Счётчики и квесты на таблицах v2 (багфикс)

- `counters.lexicon`: слова с `atom_mastery.strength >= 2`, фильтр «только слова»
  через `content.get_course()` (id слов модулей; фразы `*.pN` и грамматика не считаем).
- Беседка дня (v2-версия в `app/castle/quests.py`, старую `learn.daily_quests` не ломаем —
  её использует v1):
  - `xp-goal`: XP за сегодня из `daily_activity` (день по Москве), цель = `daily_goal_xp` профиля;
  - `lesson-1`: завершённые `learn_sessions` за сегодня (`kind='lesson'`);
  - `perfect-1`: завершённые сегодня узлы с `best_accuracy = 1` (`node_progress.completed_at` сегодня).
  - награда: 15 XP (как v1) + 5 монет каждое, тип `DAILY_QUEST_V2`,
    идемпотентность `quest-v2:{player}:{day}:{qid}`.

### T2. Сундук слов (Сокровищница)

- Порог: каждые 25 новых выученных слов (тот же счётчик, что у Словесника).
  `earned = lexicon_count // 25`, открыто — строки в новой таблице:
  `lexicon_chests(player_id, chest_index, opened_at, coins, item_id, UNIQUE(player_id, chest_index))`.
- Награда: 30 монет + случайное некупленное украшение из каталога (детерминированно:
  выбор по хешу `player_id+chest_index`, повтор не меняет; если всё куплено — 60 монет без вещи).
- API (`app/castle/api.py`):
  - `GET /api/v2/castle/lexicon-chest` → `{words, per_chest: 25, opened, ready, progress}`
    (`progress` — слов до следующего сундука);
  - `POST /api/v2/castle/lexicon-chest/open` → открыть, идемпотентность
    `lexicon-chest:{player}:{index}`; повторный вызов возвращает уже выданное.
- Вещь пишется в `castle_owned` с `source='lexicon-chest'`.

### T3. Испытание дня (Двор)

- Новый узел `TRIAL_NODE = "trial"` в `learning/sessions.py`: план — 5 слов
  (`builder.build_practice` с размером 5), отдельный `kind='trial'` в `learn_sessions`.
- Лимит: каждый ответ ≤ 15 с (`response_ms` уже пишется). `finish` считает
  `trial_passed = completed and all(ms <= 15000)`.
- Награда: +5 монет, тип `TRIAL_REWARD`, один раз в московские сутки,
  идемпотентность `trial:{player}:{day}`; без прохождения — не даётся.
- Ветка Тренера: `counters.yard` считает `kind IN ('practice','trial')`.
- API: статус в ответе двора — `GET /api/v2/practice/status` →
  `{trial_done_today, trial_available}` (есть ли что испытывать — как у practice);
  старт — `POST /api/v2/practice` с `{"mode": "trial"}`.

### T4. Задания недели (Беседка)

- Три недельных (окно = московская неделя, `league_weeks.week_start`):
  - `week-lessons`: 5 уроков за неделю → 30 монет;
  - `week-practice`: 3 тренировки/испытания → 20 монет;
  - `week-words`: 25 новых слов (рост счётчика Словесника за неделю: атомы со
    `strength>=2`, впервые достигшие порога на этой неделе — по `updated_at` atom_mastery) → 20 монет.
- Тип `WEEKLY_QUEST`, идемпотентность `quest-v2:{player}:{week_start}:{qid}`.
- `GET /api/v2/quests` → `{daily: [...], weekly: [...]}`, у каждого задания поле
  `spot` (id здания для подсветки: school/yard/lexicon) и `href`;
  `POST /api/v2/quests/claim` `{quest_id, period: "day"|"week"}`.

### T5. Трофеи лиги (Башня Славы)

- `learn.league()` += `history`: последние 8 закрытых недель из `league_weeks`
  (`week_start, rank, weekly_xp, coins_awarded`), свежие первыми.
- Фронт рисует список с медалью для мест 1–3.

### T6. Фронтенд (всё в `world/src`)

- Сокровищница (`lexicon`): карточка сундука — прогресс «12/25», кнопка «Открыть»
  при `ready`; после открытия — что выпало (монеты + вещь с картинкой).
- Двор (`yard`): карточка «Испытание дня»: состояние (доступно/пройдено/завтра),
  переход на `/lesson/practice?mode=trial`; на экране урока — таймер 15 с на вопрос
  (полоса, по таймауту ответ засчитывается неверным), финиш — «испытание пройдено».
- Беседка (`quests`): две секции «Сегодня» и «Неделя», кнопки «Забрать»,
  клик по заданию — переход с подсветкой здания (`journey.ts`, `/world?pulse=<spot>`).
- Башня Славы (`glory`): блок «Трофеи» — история недель с медалями.

### T7. Прогоны, e2e, журнал, пуш

- `world-backend/.venv/bin/python -m pytest -q`; `world`: `npm test`, `tsc`, `eslint`;
  e2e `castle-quests.spec.ts` (сундук, задания, трофеи) и `castle-trial.spec.ts`.
- DEVLOG + push. Деплой — по подтверждению владельца.

## Правила (как в этапе 1)

- Начисления и списания — только на сервере, всё с ключами идемпотентности.
- TDD: красный тест → реализация → зелёный → коммит.
- Русские тексты интерфейса, TypeScript strict без `any`.
- Не делаем: визиты к друзьям, события, питомца — отложено владельцем.
