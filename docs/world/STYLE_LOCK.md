# 🔒 Мир Фоксинбурга — ЗАФИКСИРОВАННЫЙ стиль «Живая миниатюра»

**Статус:** утверждён владельцем 2026-09-17. **Обязателен для всего проекта «Мир Фоксинбурга»**
(`world/`, `world-backend/content`, `world-pipeline/`).

## Правило изменений

1. Этот стиль и дизайн **никто не меняет по своей инициативе** — ни агенты, ни разработчики.
2. Меняется **только та деталь, которую владелец явно и чётко назвал**. Всё остальное остаётся
   ровно как было.
3. Любые «улучшения», редизайны, смена палитры, шрифтов, материалов, модели генерации или
   промптов без прямого указания владельца — **запрещены**.
4. Новые экраны, модули и картинки делаются **строго в этом стиле**.
5. Документы `docs/world/world-art-bible.md`, `FOXINBURG_WORLD_MASTER_PROMPT.md` и прочие старые
   описания стиля, если противоречат этому файлу, — **устарели**; действует этот файл.

## Арт (генерация)

- Модель Meshy: **`gpt-image-2-5-flare`**. Другие модели не использовать.
- Промпты и формулы — **только** из `world-pipeline/prompts/ART_DIRECTION.md` и
  `world-pipeline/diorama_art.py` (ядро стиля `CORE` не менять).
- Всё — фотореалистичная рукотворная диорама, макросъёмка, tilt-shift, мягкое боке, материалы:
  лавандово-серый камень, мох и плющ, состаренный дуб, латунь, сливовая черепица, тёплый свет окон.
- Фон интерфейса — размытый сумеречный лес и далёкие горы в том же стиле.

### Башни классов (одобрено владельцем 2026-09-17)

У каждого учебника своя башня, темы — `TOWER_THEMES` в `world-pipeline/diorama_art.py`:
Spotlight 1 — стройная башня с плющом; Spotlight 2 — «Башня мастеров» (водяное колесо, мастерская,
мостик); Spotlight 3 — «Башня звездочётов» (обсерватория с телескопом); Spotlight 4 — «Башня
путешественников» (маяк у моря, гавань, воздушный шар). Эти башни — будущие здания Замка.

### Замок Фоксинбург (одобрено владельцем 2026-09-17)

- Экран `/world` — одна цельная диорама `world/public/content/castle/castle-diorama.webp` на весь экран
  (лес, туман, горы вокруг), без склейки спрайтов поверх картинки.
- Башни классов SP1–4 **и есть** угловые башни замка: растут от земли, стены входят в них; никаких
  каменных башен под ними и подставок. Здания стоят на земле двора/луга, без круглых подставок.
- Клик/hover — по силуэту здания (карта зон `castle-hotspots.png` + маски `masks/*.png`); hover —
  только золотое свечение и латунная подпись, без подъёма и увеличения.
- Заголовок — «Замок Фоксинбург» + подсказка, что можно найти в зданиях; не «награда за учёбу».
- Пересборка — только `world-pipeline/castle_compose.py` (compose → fuse → masks), модель flare.
- Внутри здания: интерьер на весь экран, плашка внизу из пергамента-вуали `mat-parchment-veil` (интерьер
  просвечивает), кнопки — латунь/эмаль/бумага из `@/design/Button`; альбом стикеров — эмалевые карточки.

### Картинки слов

К промпту слова всегда добавляется `NOT_A_HOUSE` — иначе ядро стиля превращает предметы в домики.

Экономия (одобрено владельцем 2026-09-17): предметы, животные и отвлечённые слова можно делать
моделью `nano-banana-2` с уточнением композиции `BUDGET_TUNE` (флаг `--budget` в `diorama_art.py`);
люди/персонажи (`PEOPLE_WORDS`), этажи, башни, фоны и спрайты — только `gpt-image-2-5-flare`.

## Интерфейс

- Объёмный, не плоский. Материалы: латунь (`mat-brass`), эмаль (`mat-enamel`), пергамент
  (`mat-parchment`), камень (`mat-stone`), тёмное дерево (`mat-wood`), тёмное стекло (`glass-dusk`)
  — `world/src/app/globals.css`.
- Путь обучения — башня замка: башня-герой, этажи-диорамы модулей, окна-уроки (спрайты
  `window-lit / dark / shutters / chest / balcony`), лестницы, Foxy у текущего окна.
- Урок: размытая диорама этажа на фоне, задание на пергаменте, эмалевые варианты, латунные
  кнопки и прогресс-трубка, лист результата на тёмном дереве.
- Шрифты: Playfair Display (заголовки, `font-fairy`), Nunito (текст). Маскот — Foxy по брендбуку.

### 3D-маскот Фокси (утверждено владельцем 2026-09-18)

Фокси у окна текущего урока в башне — живой 3D-маскот, а не статичный спрайт.

- Модель: `world/public/assets/foxi-rigged-v2.glb` (889 КБ, draco + webp512). Клипы:
  `Idle` (4.03с), `Walk_Inplace` (4.23с), `Walking`, `Running`, `Call_Gesture` (7.57с),
  `Big_Wave_Hello` (5.3с), `Cheer_with_Both_Hands_Up` (1.9с), `Happy_jump_f` (9.8с),
  `Shake_It_Off_Dance` (16.3с). Пайплайн: `world-pipeline/foxi_animate.py`, `merge_clips.py`.
- Поведение у окон (`world/src/foxi3d/`, чистый three.js без R3F; `Tower.tsx` → `<FoxiMascot/>`):
  стоит у текущего окна (`Idle`, изредка `Big_Wave_Hello`), периодически переходит к соседнему
  окну (`Walk_Inplace` + смещение и поворот корпуса, хвост — процедурно, кость `Tail`),
  при долгом простое — `Call_Gesture` + бабл «Нажми на следующий урок!» (DOM поверх canvas,
  латунь/пергамент-токены), по пульсу нового урока (`?pulse=`, события `foxi:celebrate` /
  `foxi:dance`) — `Cheer_with_Both_Hands_Up` + `Happy_jump_f` или короткий фрагмент
  `Shake_It_Off_Dance`.
- Фолбэки: `prefers-reduced-motion`, нет WebGL или ошибка загрузки GLB → статичный
  `/content/foxy/wave.webp`. Кнопка «Спрятать Фокси» (localStorage `world-foxi-hidden`),
  возврат — «Позвать Фокси». Canvas `aria-hidden`, бабл — `role="status"` polite.
- Производительность: three.js и GLB — dynamic import после `requestIdleCallback` и только
  когда маскот во вьюпорте (IntersectionObserver), pixelRatio ≤ 2, пауза при скрытой вкладке /
  вне вьюпорта, полный dispose при unmount. Draco-декодер — локально из `world/public/draco/`
  (без CDN).
