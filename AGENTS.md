# AGENTS.md

Единый источник правил для всех AI-агентов в этом репозитории — см. [`CLAUDE.md`](./CLAUDE.md).

Файл разделён на два, чтобы инструменты, читающие `AGENTS.md` (Codex и др.),
и Claude Code, читающий `CLAUDE.md`, работали по одним и тем же правилам без
дублирования и риска рассинхронизации. Правь только `CLAUDE.md` — этот файл
менять не нужно.
