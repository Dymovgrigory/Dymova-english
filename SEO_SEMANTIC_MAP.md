Расширенная карта семантического ядра: **500+ запросов**, иерархия Pillar → Cluster → запросы.
База: `SEO_semantic_core.md` (12 кластеров, ~55 запросов) и `SEO_meta_recommendations.md`.

Школа: языковая школа «Фоксинбург», Долгопрудный, Московская область.
Филиалы: Лихачёвский пр-д 76к1 и пр-т Ракетостроителей 9к3.
Аудитория: дети 2–18 лет и взрослые. Языки: английский, немецкий, китайский.
Прочие программы: подготовка к школе, русский язык и математика для дошкольников/младших школьников.

## 1. Легенда и правила

**Интенты:**
- `I` — informational (как/что/со скольки лет/почему)
- `C` — commercial (курсы/цена/отзывы/сравнение)
- `T` — transactional (записаться/купить/стоимость абонемента)
- `L` — local (гео-модификаторы, «рядом»)
- `CMP` — comparison (vs, или, что лучше)
- `B` — branded (бренд)
- `AI` — conversational (вопрос целиком, как спрашивают голосом/в ChatGPT/Алисе)

**Страницы:** существующий URL или `NEW` (страницу нужно создать). Рекомендуемые URL для NEW указаны.

**Приоритет кластера:** `P1` (делать первым) / `P2` / `P3`.

**Частотность не указана намеренно** — до выгрузки из Вордстата/Вебмастера/GSC любые цифры будут выдумкой. Методика уточнения — раздел 10.

**Гео-уровни:**
- `L1` — Долгопрудный (основной)
- `L2` — соседние локации: Хлебниково, Водники, Павельцево, Новая Дача, Виноградово, Шереметьевский, Лобня, Мытищи, Ховрино (Москва, примыкает к МКАД)
- `L3` — Московская область
- `L4` — Москва (только онлайн-формат; оффлайн-трафик Москвы не целевой)
- `L5` — Россия (только информационные запросы, ведут в блог)

**Существующие страницы (19 целевых из 39 проиндексированных):**

## 14. Методика уточнения частотности и ведения ядра

### 14.1. Выгрузка реальной частотности

1. **Яндекс Вордстат** (wordstat.yandex.ru):
   - Прогнать все запросы карты пакетно (через API Вордстата или Key Collector / Словоёб / «Мутаген»).
   - Фиксировать три значения: базовая частота, точная (`"запрос"`), по оператору `!` (точная форма).
   - Регион: «Москва и область» + отдельно «Все регионы» — для L1/L2 запросов смотреть региональную.
   - Для L2-гео (`хлебниково`, `водники` и т.д.) решение о создании `/geo/*` принимать при точной частоте ≥10/мес.
2. **Яндекс Вебмастер API** (`/v4/user/.../search-queries`):
   - После подтверждения сайта выгрузить «Поисковые запросы» за 3–6 мес: показы/клики/CTR/позиция.
   - Запросы с показами, которых нет в карте, → добавить в соответствующий кластер.
   - Запросы с показами без кликов и позицией 5–20 → приоритет на доработку Title/Description страницы.
3. **Google Search Console API** (`searchanalytics.query`):
   - Тот же разбор, dimensions `query` + `page`, диапазон 6 мес.
   - Особое внимание: AI/conversational запросы (длинные вопросы) — их GSC показывает лучше Вордстата.
4. **Яндекс Метрика → отчёт «Поисковые фразы»** — дополнительный источник реальных формулировок.
5. **Подсказки поиска** (Яндекс/Google suggest) — прогнать базовые паттерны (`английский долгопрудный *`, `английский для детей * лет`) для ловли новых хвостов.

### 14.2. Как завести ядро в БД (`seo/semantic-core`)

Рекомендуемая схема (Prisma/PostgreSQL, в рамках Foxinburg Education OS):

```
Keyword
  id            Int      @id @default(autoincrement())
  query         String   @unique          // нормализованный запрос (нижний регистр)
  cluster_id    Int      -> Cluster.id
  intent        Enum     // I | C | T | L | CMP | B | AI
  geo_level     Enum     // L1 | L2 | L3 | L4 | L5 | NONE
  target_url    String                   // существующий URL или NULL → page_needed
  page_needed   Boolean  @default(false)
  freq_base     Int?                     // Вордстат базовая
  freq_exact    Int?                     // Вордстат "точная"
  freq_updated  DateTime?
  gsc_clicks    Int?  / gsc_impressions Int? / gsc_position Float?
  yw_clicks     Int?  / yw_impressions  Int? / yw_position  Float?
  priority      Enum     // P1 | P2 | P3 (наследуется от кластера, можно переопределить)
  status        Enum     // NEW | ASSIGNED | OPTIMIZED | RANKED
  created_at / updated_at

Cluster
  id, name, pillar, priority, target_url, status

Pillar: хранить как поле pillar в Cluster (P0–P9).
```

- Импорт: этот файл → CSV (`query,intent,geo_level,cluster,target_url,page_needed`) → сид-скрипт в `seo/semantic-core`.
- Обновление метрик: cron-джоба раз в 2 недели тянет Вебмастер API + GSC API и пишет снапшоты
  (отдельная таблица `KeywordMetricSnapshot` для истории).
- Дашборд: в админке — сводка по кластерам (сумма показов, средняя позиция, % запросов в топ-10).

### 14.3. Регламент

- **Ежемесячно:** пересборка Вордстата по новым хвостам, ревизия AI-таблицы (новые формулировки из Метрики).
- **Ежеквартально:** проверка каннибализации (один интент = одна страница; если две страницы ранжируются
  по одному запросу — объединять или разводить интенты).
- **Сезонно (апрель–май):** актуализация летнего кластера (даты, цены, Title).
- **После каждого обновления ФИПИ/ФИОКО:** ревизия кластеров ОГЭ/ЕГЭ/ВПР (структура экзаменов, даты ВПР).
