# Картинки слов

Новые карточки в `_sheets/` и нарезанные `*.jpg` после 2026-09-16 —
собственная генерация Meshy (`nano-banana-pro`) для Foxinburg World.
Лицензия: права школы, коммерческое использование.

Оставшиеся старые `*.jpg` без листа — выгрузки из Wikipedia / Wikimedia
Commons скриптами `world-backend/scripts/fetch_*.py`. Автор и точная
лицензия каждой выгрузки в момент скачивания не записывались. Эти файлы
нельзя считать готовыми для продакшена: их нужно заменить фирменными
листами или удалить. Пока файл живёт на диске, он используется только
как временная заглушка учебной карточки.

Эмодзи-SVG (`*.svg`) собраны скриптом `build_word_library.py` из Twemoji
(CC-BY 4.0, Twitter).
