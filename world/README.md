# Foxinburg World

Фронтенд игрового мира «Фоксинбург» — 3D-сцена на Next.js + React Three Fiber,
в которой ребёнок проходит первый квест: находит школу, знакомится с Фокси и
проходит словарный челлендж за XP и монеты.

## Запуск

Нужен запущенный бэкенд игрового API (FastAPI, репозиторий `bot/`) на порту
`8000` — фронтенд стучится в него напрямую из браузера.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Переменные окружения

См. `.env.example`. `NEXT_PUBLIC_WORLD_API` — адрес игрового API; по умолчанию
клиент стучится в `http://localhost:8000`, переменная нужна только если бэкенд
поднят на другом хосте/порту.
