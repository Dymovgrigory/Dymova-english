# Foxinburg World

Фронтенд игрового мира «Фоксинбург» — 3D-сцена на Next.js + React Three Fiber.
Бэкенд — отдельный процесс `world-backend/` (**всегда** `127.0.0.1:8010`), не школьный бот и не CRM.

Порты закреплены за этим проектом и не прыгают:

| Что | Адрес |
|-----|--------|
| UI | [http://127.0.0.1:3002](http://127.0.0.1:3002) |
| API | [http://127.0.0.1:8010](http://127.0.0.1:8010) |

## Запуск

Из корня репозитория (освобождает 3002 и 8010, поднимает оба процесса):

```bash
make world-dev
```

Стоп: `make world-stop`.

Или по отдельности: API `uvicorn` на **8010**, фронт `npm run dev` (порт **3002**, хост `127.0.0.1`).

## Переменные окружения

См. `.env.example`. `NEXT_PUBLIC_WORLD_API` по умолчанию `http://127.0.0.1:8010`.

## Проверки

```bash
npx tsc --noEmit
```
