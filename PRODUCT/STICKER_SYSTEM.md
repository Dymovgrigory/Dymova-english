# STICKER_SYSTEM.md

Catalog: `config.STICKERS` → inventory item ids `sticker-*`.

Grants:
- Unit complete → `sticker-{unit}`
- Perfect lesson → `sticker-perfect`
- First lesson → `sticker-hello`
- Streak ≥3 → `sticker-streak` (once)

UI: room `stickers` + `StickerDrawer` / album page. Art under `/world/ui/stickers/`.
Owned count from home payload `stickers.owned`.
