# SOCIAL_SYSTEM.md

## Status

Architecture only. **Do not ship public friends until identity is real** (Phase 1 sessions). Device-local keys would make “friends” a farm.

## Target

- friends / requests  
- friend profiles (safe subset: level, stickers count, streak — not exact coins)  
- friend activity (lesson finished, not raw answers)  
- cooperative quest rewards (server split, idempotent)  
- gifts (inventory grants via ledger)  
- leaderboards = existing weekly league (already live, XP from ledger)

## Safety

- No open chat in v1 child product.  
- Teacher/parent can disable social.  
- Block / report.  
- Age-appropriate display names.

## Near-term

Keep **league** as the only social surface. It already ranks weekly XP without PvP.
