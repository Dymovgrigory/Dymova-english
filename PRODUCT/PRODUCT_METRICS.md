# PRODUCT_METRICS.md

## North-star

Child returns tomorrow **and** completes a real learning action (lesson or review), not only opens the map.

## Product

| Metric | Why |
|---|---|
| Lesson completion | Core loop |
| Review completion (due words done / due) | SRS health |
| Speaking attempts | Oral-first |
| D1 / D7 retention | Habit |
| Streak health (incl. freeze use) | Return |
| Time-to-first-reward | Onboarding |
| Duplicate reward rate | Abuse ≈ 0 |

## Guardrails

- Hearts spent vs restored  
- Shop double-charge attempts  
- TTS calls / player / day  
- League XP vs lesson XP share (farm detect)

## Source

Replay from ledgers + `lesson_progress` + `activity_sessions`. Do not trust client analytics for XP.
