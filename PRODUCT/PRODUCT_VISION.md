# PRODUCT_VISION.md

## One sentence

Мир Фоксинбурга — живой образовательный игровой мир, где ребёнок учит английский через путь, персонажа и прогресс, а не через список курсов.

## For whom

- **Child** — returns to “my world,” learns with Foxy, earns fair rewards  
- **Parent** — sees real skill progress, time, weak spots  
- **Teacher** — assigns, monitors, reports  
- **Admin** — content, economy, experiments  

## North star experience

Open app → land in Foxinburg → see next best action → complete learning → world reacts → reward → want to return tomorrow.

## Differentiation

| Pattern (industry) | Foxinburg version |
|---|---|
| Lesson list | World path: region → chapter → mission |
| Generic avatar | Foxy as guide + reaction system |
| Flat XP bar | Ledger economy + visible world unlocks |
| Sticker spam | Curated album with rarity + acquisition rules |
| Black-box AI | AI under curriculum + safety gates |

## Constraints

- Learning integrity over vanity metrics  
- Server authority for all value  
- RU/EN first; i18n-ready strings  
- Mobile-first touch targets; fullscreen learning modes
