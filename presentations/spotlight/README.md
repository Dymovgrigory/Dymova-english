# Презентации курсов Spotlight 2–5 для родителей

Четыре продающие презентации (по 14 слайдов, 16:9, формат страницы совпадает
с презентацией «Подготовка к школе») в фирменном стиле Фоксинбург.

## Сборка

```bash
python3 build.py          # HTML + PDF (нужен Google Chrome)
python3 build.py --html   # только HTML, быстро для правок вёрстки
```

## Файлы

| Файл | Что внутри |
|---|---|
| `content.py` | Весь текст: программа по модулям, грамматика, результаты, цена, педагог, данные школы |
| `build.py` | Сборка слайдов и печать в PDF через headless Chrome |
| `style.css` | Дизайн-система: цвета бренда, типографика, карточки, сетки |
| `assets/` | Обложки учебников, маскот, логотип, фото педагогов, локальные шрифты |

В `assets/` уже лежат готовые квадратные фото: `teacher-prokudina.jpg`, `teacher-vinogradova.jpg`,
`teacher-sporyhina.jpg`, `teacher-dymova.jpg` — если курс ведёт кто-то из них, достаточно указать имя файла.

Правки текста — только в `content.py`. Цена, контакты и реквизиты школы —
в словарях `PRICE` и `SCHOOL` в начале файла: меняются в одном месте сразу для всех четырёх колод.
Ссылки на карты, соцсети и сайт — в словаре `LINKS` в начале `build.py`.

### Педагог курса — заполнить

Слайд 11 рассчитан на одного преподавателя. Данные лежат в словаре `TEACHER` в `content.py`:
`name`, `role`, `bio`, `facts` и `photo`. Пока `photo = None`, вместо фотографии рисуется
плашка-заглушка «Фото педагога». Чтобы поставить реальное фото — положите файл в `assets/`
и укажите его имя в `photo` (квадратный кроп, от 520×520).

## Структура слайдов

1. Обложка · 2. Зачем нужен курс · 3. Учебник Spotlight N · 4. Результат года
5. Программа: все модули · 6. Отрабатываем до автоматизма · 7. Как проходит занятие
8. Формат обучения · 9. Приложение «Твоя школа» · 10. Контроль результата
11. Педагог · 12. О школе · 13. Стоимость · 14. Контакты (кликабельные ссылки)

## Заметки

- Обложки учебников — официальные обложки изданий «Просвещение» / Express Publishing
  (`assets/cover-sp*.jpg`), используются как указание на УМК, по которому идёт курс.
- Разговорный клуб с носителем и консультации по школьным домашним заданиям
  в презентации намеренно не упоминаются.
- Оглавление модулей сверено с учебниками: Spotlight 2–4 (Быкова, Дули, Поспелова, Эванс),
  Spotlight 5 (Ваулина, Дули, Подоляко, Эванс), редакция ФГОС 2021.
- Шрифты Comfortaa и Nunito лежат локально в `assets/fonts/` — сборка работает без интернета.
- Маскот `assets/mascot-foxinburg.png` — вырезанный из «Маскот Фоксинбург.PNG» в корне проекта.
- На последнем слайде телефоны, адреса (Яндекс.Карты), соцсети, почта и сайт — кликабельные
  ссылки, они сохраняются в PDF.
