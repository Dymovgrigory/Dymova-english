# Фокси — живой 3D-маскот на сайте

Ригнутый маскот v2 (Meshy biped, 6 скелетных клипов) гуляет по нижней полосе
экрана В ГЛУБИНУ сцены (подходит ближе к зрителю и уходит дальше), реагирует
на скролл, клики и CTA. Подключён на всех 30 страницах через
`build_static_site.py` (сессия 41 — v1, сессия 42 — v2).

## Файлы

- `mascot.js` — движок маскота (Three.js, ES-модуль, динамический импорт
  three ПОСЛЕ `load` + `requestIdleCallback` — LCP не страдает).
- `foxi-rigged.glb` — рабочая модель v2:
  `Meshy_AI_Meshy_Merged_Animations-2.glb` (51,85 МБ) → правка скиннинга
  (см. ниже) → `@gltf-transform/cli optimize --compress draco
  --texture-compress webp --texture-size 512 --simplify false` → **726 КБ**.
  6 клипов: Walking, Running, Big_Wave_Hello, Cheer_with_Both_Hands_Up,
  Happy_jump_f, Shake_It_Off_Dance. Кости: `Head` (взгляд), `Tail` (хвост).
- `foxi-rigged-v1-17clips.glb` — модель v1 (17 клипов, сессия 41), бэкап.
- `foxi.glb` — старая статичная модель без рига (про запас, не подключается).
- `index.html`, `test-rigged.html` — локальные демо/стенд (`?h=2.6` — крупно).

## Правки скиннинга v2 (скрипт на Python, numpy+PIL)

Исходный GLB от Meshy имел дефекты авто-рига — исправлены в бинарнике:

1. **Хвост** — в скелете не было кости хвоста, 254 вершины хвоста сидели на
   `Hips` и в танцах жёстко улетали вперёд/вбок сквозь тело. Добавлена кость
   `Tail` (25-й joint, ребёнок `Hips`, локальная матрица — полная, т.к.
   `Armature` со scale 0.01), вершины хвоста перевешены на неё (100%).
   В `mascot.js` хвост управляется процедурно: держит направление «назад»
   от рига с упругим запаздыванием (slerp) + виляние (быстрее при движении).
2. **Лямки и рюкзак** — 273 фиолетовые вершины (выборка цвета из текстуры по
   UV: purple & y>0.48) сидели на `Left/RightShoulder`, `Head`, `neck`,
   `LeftArm` и тянулись за руками/головой. Перевешены на `Spine02` (100%).
3. **Материал** — был `alphaMode: BLEND` + `doubleSided` (мерцание/просветы
   при сортировке) и `KHR_materials_specular` [2,2,2]. Теперь `OPAQUE`,
   specular 1.0, эмиссия умеренная 0.45 (текстура читается со всех сторон,
   но свет работает). Лапы с «пальцами» — это дизайн модели, не глюк.

## Поведение (все 6 клипов задействованы)

| Контекст | Клип |
|---|---|
| idle (база) | Shake_It_Off_Dance на timeScale 0.18 — еле заметное покачивание |
| скролл вниз | Walking (шагает вправо) |
| скролл вверх | Walking (шагает влево) |
| быстрый скролл (>2600 px/с) | Running по направлению скролла |
| рывки туда-сюда (3+ смены направления/1.2с) | Happy_jump_f («испугался») |
| доскроллил до низа страницы | Shake_It_Off_Dance (танец, раз в 60 сек) |
| наведение на CTA заявки | Big_Wave_Hello (кулдаун 10 сек) |
| клик по CTA | Cheer_with_Both_Hands_Up ×1.3 (кулдаун 10 сек) |
| клик рядом с маскотом | Happy_jump_f (иногда Big_Wave_Hello) |
| скука (каждые 9–20 сек) | прогулка Walking в случайную точку 3D-сцены / выход к зрителю (подходит ближе, машет, возвращается) / Big_Wave_Hello / Cheer / танец |
| курсор рядом | голова (кость `Head`) следит за мышью поверх клипа |

## Глубина (3D)

Дорожка — полоса z от `depthFar` (−3.2) до `depthNear` (1.6), камера на z=8.
«Пол» под маскотом пересчитывается под его глубину каждый кадр
(`screenFracFar` 0.78 → `screenFracNear` 0.95): далёкий маскот стоит выше на
экране и меньше, ближний — ниже и крупнее. Прогулки (`startStroll`) идут к
случайной точке (x, z) с разворотом в сторону движения (`yaw = atan2(dx, dz)`);
`startVisit` — подход к зрителю, махание, возврат.

## Не мешает читать

- живёт в нижней полосе экрана, стартует у левой кромки;
- canvas `pointer-events: none` — клики проходят сквозь;
- правый нижний угол (чат-виджет) — запретная зона (`reserveRightPx`);
- скрытая вкладка — рендер на паузе; `prefers-reduced-motion` и слабые
  устройства (hardwareConcurrency<4, deviceMemory<4, saveData) — маскот
  не загружается вовсе.

## Подключение (уже встроено в build_static_site.py)

```html
<script type="importmap">{"imports":{"three":"…0.180.0/build/three.module.js",
"three/addons/":"…0.180.0/examples/jsm/"}}</script>
<script>window.FOXI_CONFIG={modelUrl:'/mascot/foxi-rigged.glb'};</script>
<script type="module" src="/mascot/mascot.js"></script>
```

ВАЖНО: importmap обязан идти раньше первого `<script type="module">`
на странице (поэтому в WOW_SNIPPET он первой строкой).

## API для сайта

`window.FOXI` (после загрузки модели): `wave()`, `jump()`, `dance()`,
`walk()`, `visit()` (подойти к зрителю и помахать), `config` (FOXI_CONFIG),
`_state`/`_scroll` — отладка.

## Конфиг (`window.FOXI_CONFIG`)

| Ключ | По умолчанию | Описание |
|---|---|---|
| `modelUrl` | `./foxi-rigged.glb` | путь к GLB |
| `headBone` | `head` | подстрока имени кости головы |
| `height` / `mobileHeight` | `1.0` / `0.72` | высота маскота (автомасштаб) |
| `faceOffset` | `0` | добавка к yaw (модель смотрит в +Z) |
| `walkSpeed` / `runSpeed` | `1.7` / `3.6` | юнитов/сек |
| `depthNear` / `depthFar` | `1.6` / `-3.2` | границы дорожки по глубине |
| `screenFracFar` / `screenFracNear` | `0.78` / `0.95` | высота «пола» на экране (даль/близь) |
| `reserveRightPx` | `120` | запретная зона справа (чат-виджет) |
| `minDelay`/`maxDelay` | `9`/`20` | паузы между «поступками», сек |
| `hideUnderWidth` | `0` | >0 — отключить на узких экранах |

## Замена модели

Если пришлют новый GLB: проверить скиннинг (хвост/рюкзак — см. правки выше,
скрипт в сессии 42 из DEVLOG), прогнать через gltf-transform (команда выше),
проверить имена клипов (парсинг GLB JSON или консоль `[foxi]`), при другом
направлении лица подобрать `faceOffset` (0 или `Math.PI`).
